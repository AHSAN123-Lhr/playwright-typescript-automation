# Playwright TypeScript Automation Framework

## Overview

Automation framework built using Playwright and TypeScript for testing the Automation Exercise e-commerce website.

## Tech Stack

- Playwright
- TypeScript
- Node.js
- Git & GitHub
- GitHub Actions
- REST API Testing

## Automated Testing

### UI / E2E Testing

- User registration
- Login / Logout
- Product search
- Product details verification
- Add product to cart
- Cart verification
- Checkout
- Delivery and billing address verification
- Payment
- Order placement verification
- Account deletion

### API Testing

- Get products list API
- Product data validation
- Invalid login API
- Status code and response validation
